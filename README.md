# 旅ログ Ver.1.2.9 — Googleタイムラインの日付補正

GitHub Pages では **index.html** のみを置き換えてください。`sw.js` は必要ありません。

## 変更点

- GoogleタイムラインiPhone版で、`+09:00` と `Z` (UTC) が混在する日時を統一して日付判定します。たとえば `2026-10-29T21:00:00Z` は日本時間 **2026/10/30 06:00** として扱います。
- 「この日のGoogle記録を入れ直す」ボタンを追加。同じ旅にある、選択した日付のGoogleタイムライン由来の区間だけを確認後に置換します。手描き線・GPX・他の日付は維持します。
- 再生距離を「描画線の長さ（概算）」と明示。Googleマップの移動距離と、地点間を直線で結んだ距離は異なる場合があります。
- 既存の実地図・会場図・手描き・旅切替・移動手段・GPX/GeoJSON・JSONバックアップ機能を維持。

## 実機での再確認

1. **重要**: 更新前に旅ログのJSONバックアップを保存してください。
2. GitHub Pages の `index.html` を差し替えます。
3. 「移動履歴を取り込む」からiPhoneで書き出したGoogleタイムラインのJSONを指定します。
4. 日付を `2026/10/29` にして確認。添付のテストデータでは**15区間・76地点**が表示されます。
5. 既存の旅に取り込んでいる場合は「この日のGoogle記録を入れ直す」を選ぶと、その日のGoogle区間だけ更新されます。以前の手描き線も合算されるので比較には向きません。
6. Googleの移動結果と純粋に比較するなら、**「新しい旅として保存」**を選んでください。日付も旅のタイトルに入ります。

ブラウザ環境で操作・取り込み・入れ直しを検証済み。iPhone Safari実機での最終動作は未確認です。

個人の移動履歴JSONを、公開GitHubリポジトリにアップロードしないでください。
