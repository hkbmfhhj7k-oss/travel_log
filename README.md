# 旅ログ Ver.1.2.5 — GPSログ取り込み／区間編集

## 更新
GitHub Pages の既存 `index.html` をこのフォルダの `index.html` に置き換えてください。`sw.js` は不要です。重要なデータは先に「バックアップを書き出す」で JSON を保存してください。

## 今回の追加
- 実地図の「ほかのアプリの移動記録を取り込む」から GPX (`.gpx`) / GeoJSON (`.geojson`, `.json`) を選択。
- 読み取り結果を確認後、「この旅に追加」または「新しい旅として保存」を選択。
- 取り込んだ経路は「不明・その他」モードとして登録。区間一覧から徒歩・電車・バス等へ変更可能。
- 経路一覧から「地図で見る」（位置へ移動し強調表示）、「削除」（確認あり／戻す可）。
- GPSトラックは形状をなるべく保ちながら表示用に間引いて端末内保存。GPX原本は編集しません。
- GPXの日時情報は利用可能な点で記録。時刻に基づく再生機能はまだありません。

## 対応する入力
- GPX: `trk`→`trkseg`→`trkpt`、`rte`→`rtept`。単独の `wpt` は対象外。
- GeoJSON: `LineString` / `MultiLineString` / `FeatureCollection` のライン。点・面は対象外。
- 取り込み上限 12MB・元地点合計 65,000・区間 1,500。複数の区間を勝手に直線接続しません。
- ファイルはブラウザ内で読み込みます。地図背景の表示には従来通り通信が発生します。

## 維持した機能
- 実地図（オンライン地図タイル）と会場図の切り替え
- 指で描く／点を置く／移動・ズーム／消去／戻す／やり直す
- 手描きルートを区間分け・近い線の結合・移動手段の指定
- 旅ごとの端末内 IndexedDB 自動保存、JSON バックアップと旧版読み込み、経路再生

## 制限
- iPhoneのバックグラウンドGPS自動記録機能ではありません。GPSログは別途GPX/GeoJSONを生成できるアプリ等が必要です。
- Apple標準の「マップ」の行動履歴を直接読み出す機能ではありません。
- Safariのデータを消すと端末内保存も消える可能性があるため、必ずJSONのバックアップを利用してください。
- iPhone Safari実機は未検証。Chromium上ではファイル取り込み・区間編集・旧版JSON復元・会場図での手描きを確認しました。
