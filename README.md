# 旅ログ Ver.1.2.7｜GoogleタイムラインJSON取込（iPhone優先）

## 更新方法
GitHub Pages上の `index.html` をこの ZIP の `index.html` と置き換えてください。`sw.js` は必要ありません。更新前に必ず旅ログの **JSONバックアップ** を保存してください。既存の旅・手描き経路・会場図を削除する変更はしていません。

## Googleタイムラインのエクスポート（iPhone）
Googleマップ → プロフィール → 設定 → 個人的なコンテンツ（表示名が異なる場合もあります） → タイムライン データをエクスポート → ファイルに保存。

## 取込み操作
旅ログで「実地図で描く」→「移動履歴を取り込む」→ `location-history.json` を選ぶ → 日付を選ぶ → プレビューで件数を確認 → 「この旅に追加」または「新しい旅として保存」。

- iPhoneの配列形式JSON、Androidの `semanticSegments` JSON、旧Takeoutの一部、および従来のGPX・GeoJSONに対応。
- Googleタイムラインには移動経路の詳細がない場合があります。その場合は「開始／終了地点」「訪問地点」を個別に表示し、間を勝手に直線でつなぎません。
- Googleの移動手段は推定。手描きで補完し、区間一覧から変更できます。
- 同じ形式・同じ日付の同一経路の再取込は識別子によって重複を抑制します。ただし、Google側で書き出し内容が変化すると完全な重複排除は保証できません。
- インポートするファイルは端末内で解析。位置履歴の内容をサーバーにアップロードしません。背景地図の画像読み込みはオンライン通信を使用します。
- ファイル上限40MB。GPSログの再生は実測移動時間ではなく距離と移動手段からの早送りです。
- **iPhone Safariの実機での取込・永続保存確認はまだです**。エラー時は私的な位置履歴を丸ごと共有せず、画面のエラー文をお知らせください。
