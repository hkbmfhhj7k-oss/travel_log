# 旅ログ Ver.1.3.0

Ver.1.2.10から**バージョン表示だけ**を変更した版です。新機能・操作・保存形式・DB構造の変更はありません。

## 変更点
- ブラウザのタブ名: Ver.1.2.10 → Ver.1.3.0
- アプリ画面の表示: Ver.1.2.10 → Ver.1.3.0
- HTMLバージョン識別用メタ情報 `app-version=1.3.0` を追加（機能への影響なし）

## GitHub Pagesへの反映
リポジトリで既存の `index.html` を同名のまま差し替えてコミットしてください。ZIPをそのままアップロードするのではなく、ZIPを解凍した中の `index.html` を使います。
ブラウザに古い画面が残る場合は、しばらくしてからSafariでリロードしてください。
保存データの保護のため、更新前のJSONバックアップを推奨します。
