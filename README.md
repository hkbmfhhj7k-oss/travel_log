# 旅ログ Ver.1.1｜AGF会場迷子ログ

## GitHub Pagesに置く方法

同じフォルダにある `index.html`、`sw.js`、`demo.html` を GitHub Pages リポジトリの公開ルートにアップロード（既存の `index.html` は置き換え）。iPhone Safari で GitHub Pages の URL を開いてください。PCブラウザでも動きます。

* `index.html` は **ネット通信なしでも編集できる**会場図エディターです。外部の地図ライブラリを使っていません。
* `sw.js` は一度オンラインで開いた後にアプリ本体をオフラインで使うためのキャッシュです。環境によりキャッシュが消えることがあるため、オフライン動作は事前に機内モードでテストしてください。
* `demo.html` は前の MapLibre / OpenFreeMap 実地図デモです。**こちらはオンライン地図タイル通信が必要**です。前版を残すためのファイルで、AGF当日用のGPS取得機能ではありません。

## 操作

1. 「会場図を読み込む」から画像を選択（なくても自由に経路を描けます）。
2. **線を描く**：1本指ドラッグで経路を記録。指を離すたび確定。近い終点なら続きとしてつなぎ、離れていれば別区間とします。
3. **点を置く**：1本指タップで場所を置く。同じ区間に続けたい場合は前の点の近くをタップ。
4. **地図を動かす**：1本指ドラッグで移動。どのモードでも **2本指でパンとピンチズーム** できます。
5. **線を消す**：消したい線をタップすると、その区間を削除。**戻す**で復元可。
6. 「次は別の区間」を押すと、記憶の曖昧な部分を飛ばして新しい区間を描けます。
7. 旅・画像・経路は端末の IndexedDB に自動保存。複数の旅を作成して切り替えられます。
8. **バックアップを書き出す**：画像を含む旅のJSONをダウンロード。「バックアップを読む」で新しい旅として復元できます。

## 保存とプライバシー

* `trips`: 旅ID・名前・日付文字列・メモ・normalized route points・画像参照ID、`assets`: 元画像Blob の2ストアに分離。
* 大きな画像は35MBまで。画像はDB内部ではBase64に変換せずBlobとして保存します。クラウドDB同期に置き換える場合は、保存処理と画像保管処理のみ別実装にできます。
* GitHub Pagesに掲載するのはアプリの**コードだけ**。利用者が選んだ会場図や編集データを自動公開しません。画像・経路はブラウザ内に保存されます。
* Safariの履歴・Webサイトデータを消すと IndexedDB とキャッシュが失われる可能性があります。JSONバックアップを適宜書き出してください。
* 旧Ver1.0の `travel-venue-v1` localStorage があり、新版の旅がまだ一つもない場合は起動時に一度インポート。旧データは削除しません。旧版のJSONバックアップにも対応。
* **GPS自動記録、OSバックグラウンド記録、GPX取り込みは未実装**です。Safariを閉じたまま自動追跡はできません。
* GPSデータなどの外部送信はしません。地図通信は `demo.html` を開いたときだけ生じます。

## 実装・今後

* 座標は画像または未画像キャンバスに対する正規化座標 (x,y ∈ 0..1)。図面をズームしても経路はずれません。
* 旅の構造はversion:2、各描画区間は固有ID。今後のフロア図増設、クラウド同期、経路取り込み、記録の再生に拡張できる形にしています。
* 画像交換時、既存経路は消えません。ただし別の縦横比や別レイアウトの図に交換すると視覚的な位置がずれる可能性があります。
