# 旅ログ Ver.1.3.3 — GPS点をつなぐ・既存の移動手段を変更

Ver.1.3.2からの機能追加です。既存の地図・会場図・Googleタイムライン／GPX／GeoJSON・旅データ・手描き機能を維持します。

## 追加
- 実地図の「⤴ 点をつなぐ」：既存のGPS/手描き点を2つ順にタップして独立した補完線で接続（元のGPS区間には変更なし）。線の移動手段は「不明」から選択可。離れた点も明示的に接続可能。ドラッグは地図移動。
- 実地図の「◉ 線を選ぶ」：既存の線をタップして、地図の直下に現れる選択欄から徒歩・車・電車・バス・自転車・不明へ変更。Googleタイムライン/GPXの取り込み後にも対応。
- 継続：区間の「元のGPSに戻す」、取り消し・やり直し、端末内保存、JSONバックアップ。

## 注意
- 追加する接続線は **実測ではなく、手動で推定した補完線** です。直接結んだ直線が実際の道路と一致する保証はありません。必要に応じて「◇ 線を修正」で曲げられます。
- 移動手段の変更は区間単位です。1区間の途中だけを変更したい場合は、分割機能が必要です（未実装）。
- 手動接続線は経路再生時、1点目を選んだ区間の次に再生されます。非連続の区間をまたいだ厳密な時系列再構成は未対応です。
- 保存済みデータの破壊を避けるため、更新前にJSONバックアップを取得してください。
