# 旅ログ Ver.1.2.1 — 旅の切り替え修正版

**修正内容:** 旅を切り替えるとき、切り替え前の旅の保存で選択欄が元に戻ってしまう不具合を修正しました。選択先のIDを先に確保してから保存し、正しい旅を開きます。旅の切り替えは既存機能です。

**データ:** IndexedDBのデータベース名と保存形式は変更しません。Ver.1.2からの更新で保存済みの旅が消えない想定ですが、事前に大切な旅はJSONバックアップを書き出してください。

**更新方法:** `index.html` と `sw.js` をGitHub Pages上の同名ファイルと置き換えてください。`demo.html` はそのままでも構いません。更新後にSafariで再読み込みしてください。

# 旅ログ Ver.1.2 — 実地図＋会場図の統合版

v1.1で実地図がトップ画面から消えてしまった問題を修正しました。実地図上で手描きでき、以前の会場図エディターも切り替えて使えます。

## GitHub Pagesへの更新

同じフォルダ内の3ファイル `index.html` / `demo.html` / `sw.js` を、GitHub Pagesの公開ルートへアップロードしてください。既に同名ファイルがあれば置き換えます。`README.md` は任意です。

**重要:** GitHubのリポジトリへはアプリのコードだけをアップロードしてください。自分の旅のJSONバックアップやGPSログ・写真はアップロードしないでください。公開Pagesでは誰でもファイルを見られます。

Safariで開き、更新後に旧画面が出たら一度再読み込みしてください。古いService Workerが残る環境では一度タブを閉じて開き直す必要がある場合があります。

## 使い方

### 実地図で描く（標準の画面）

* **線を描く**：1本指で道路や歩いた場所をなぞると、地理座標で保存します。近い終点なら線をつなぎます。遠い位置なら新しい区間になります。
* **点を置く**：地図をタップ。既存ルートの線の近くなら途中へ挿入し、無関係な遠い線に結びません。
* **地図を動かす**：1本指ドラッグで地図移動。どのモードでも2本指ピンチで移動・ズームできます。
* **線を消す**：近くの線をタップすると区間を削除。戻す/やり直すに対応。
* **次は別の区間**：離れた場所へ移動した経路を勝手に接続しないよう、手動で区切れます。
* **再生**：描いた実地図ルートの上を丸いマーカーで再生。車・電車のデモ再生は `demo.html` に残しています。
* **池袋へ**は初期位置に戻す操作です。「経路全体」は描いた地点に合わせて表示します。

**注意:** 実地図はMapLibre GL JS + OpenFreeMapのオンライン地図です。道路や線路への自動マッチングはまだありません。地図の表示には通信が必要ですが、ルート座標は自動的に外部サービスへ送信しません。

### 会場図で描く

* 「会場図で描く」に切り替え、写真や公式会場図を読み込んでください。
* 会場図でも、線を描く・点を置く・2本指拡大/移動・区間分け・消去・戻す/やり直すができます。
* 実地図のルートは `geoSegments`（経度・緯度）、会場図のルートは `segments`（画像内相対座標）として**同じ旅に別々に保存**します。

### 保存とバックアップ

* v1.1と同じIndexedDB (`travel-log-agf`) に保存します。以前の旅・館内図・メモは削除しません。
* インポート・エクスポートのJSONはバージョン2のまま、追加フィールドで実地図の経路を含みます。
* `assets` に画像Blob、`trips` に旅と経路を管理する構造は維持しています。
* SafariのWebサイトデータを消すと記録が消える場合があります。JSONバックアップをファイルアプリ等へ保存してください。

## 通信とオフライン

* 会場図モードでの描画・保存はオンライン地図サービスを必要としません。地図が読み込めない時も会場図エディターで編集できます。
* 実地図モードの初回読み込み・地図タイルは通信が必要です。 `sw.js` は同一オリジンのアプリ画面の基本キャッシュのみで、外部地図タイルのオフライン表示は保証しません。
* GPSの自動取得・バックグラウンド記録・GPX/外部履歴の取り込みは**まだ未実装**です。
